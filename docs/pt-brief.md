# 구조 1분 설명 (2차 PT 기술 Q&A용)

1. **한 줄**: 차 신호·음성은 `pleos/`, 이용 흐름은 `session/`, 놀이 내용은 `game/`, 화면은 `ui/`. 각 층은 아래층 인터페이스만 안다(docs/architecture.md 그래프).
2. **PleosClient**: Pleos SDK(Vehicle, NaviHelper, STT, TTS, FusedLocation)를 인터페이스 하나 뒤에 숨긴다. 테스트는 Fake, 디버그 빌드는 `sim.sh` 브로드캐스트로 같은 길을 탄다.
3. **SessionController**: 시작·멈춤·휴식·종료를 한곳에서 정한다. 멈춤 기준은 "주행 상태 × 신호 결정표"(SafetyRules). 방향지시등·브레이크는 멈춤, 경고는 소리 없이 종료, 주차가 아니면 시작 차단.
4. **GameSession 계약**(`game/api`): 입력(답·도착 등) → 출력(말할 것·다음 단계). 게임은 차량·화면을 모른다. 그래서 관찰 미션과 말잇기를 같은 이용 흐름에 바꿔 끼운다(`giltam`: 미션 3개마다 말잇기).
5. **장소 미션**: PlaceSource가 앞 150~500m 장소를 주면 장소 미션, 실패·동의 전이면 기본 미션으로 게임 안에서 전환한다.
6. **안전**: 주행 중 터치 UI 없음, 위치는 주차 중 동의 후에만, 녹음은 주차 중에만.

예상 질문은 15번 항목(PT 안정화)에서 30개로 확장한다.
