## 하지 않는 것
- 폰 앱을 차 화면에 옮긴 것처럼 보이는 기능
- 화면을 봐야 하는 게임, 터치 조작
- 시연에서 재현할 수 없는 기능(실제 도로에서만 의미 있는 것)
- 데이터 출처가 확정되지 않은 기능을 대체 경로 없이 1차 범위에 넣는 것(F-11은 실패 시 F-07로 자동 전환되므로 1차 허용, D-015)
