# 시연 영상 대본 (60~90초)

화면: Virtual Console + 앱 분할. 하단 자막에 신호 로그. sim.sh로 넣은 신호 장면은 "시뮬레이션" 자막을 붙인다.

| 시간 | 장면 | 조작 | 말·자막 |
|---|---|---|---|
| 0:00~0:10 | 문제 제기 | 앱 홈 | "아빠, 언제 도착해?" — 뒷좌석 아이와 말로만 노는 앱 |
| 0:10~0:20 | 주행 중 시작 차단 | Virtual Console D단 → 시작 | "주차 상태에서 시작할 수 있어요" (안전 우선) |
| 0:20~0:35 | 주차 시작·난이도 | P단 → 시작 → "중급" | 아이 목소리 차례 표시. 이후 화면은 요약 패널만 |
| 0:35~0:50 | 관찰 미션 | 주행 중 `sim.sh stt "빨간 간판"` (시뮬레이션) | 정답 → 칭찬. 장소 데이터 미션 `MISSION source=PLACE` 자막 |
| 0:50~1:05 | 차량 신호에 반응 | `turn-left` → 즉시 멈춤 → 끄면 이어서 | "방향지시등엔 말을 멈춰요" / `wiper-on`(정차) "와이퍼 출동!" |
| 1:05~1:15 | 경고는 무음 종료 | `warning` | 소리 없이 종료 |
| 1:15~1:30 | 벌써 도착 | `nav-arrive` → 주차 → 결과 화면 | "벌써 도착했어요! 오늘 미션 n개 찾았어요" |

준비: 시연 경로 `./scripts/route.sh scripts/routes/sejong-daero.gpx`, 중계 서버(PC)를 켠 상태에서 촬영. 서버를 끄면 `MISSION source=BASIC`으로 이어지는 장면을 덤으로 넣을 수 있다.
