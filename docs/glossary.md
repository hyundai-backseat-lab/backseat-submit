# 용어집

이 앱에서 쓰는 말을 안드로이드를 모르는 사람 기준으로 풀어 쓴다. 새 용어·패키지가 생기면 같은 PR에서 추가한다(패키지는 check-docs.sh가 검사).

## 우리 앱의 말
| 용어 | 뜻 |
|---|---|
| 결정적 장면 | 시연에서 "폰으로는 안 된다"를 보여주는 순간 3개(안전 멈춤, 아이 목소리 반응, 벌써 도착 엔딩) |
| 결정표 | 주행 상태(주차·정차·저속·주행) × 신호(방향지시등·브레이크·비상등·다른 음성 안내·경고·도착)마다 계속·멈춤·종료를 정한 표. docs/features.md 공통 정책 |
| 주행 / 저속 / 정차 / 주차 | 속도가 SDK에 없어 기어·브레이크·주차 브레이크로 추정한 주행 상태(features.md 공통 정책). 모르면 결정표에서는 주행으로 본다 |
| 멈춤 / 재개 | 차량 신호·다른 음성 안내 때문에 300ms 안에 앱 발화 정지 / 멈춤 사유가 모두 풀리고 1초 뒤 끊긴 문장만(듣던 중이면 듣기만) 다시 |
| 목소리 카드 | 아이가 녹음한 짧은 문장. 미션 안내와 차량 반응(와이퍼·도착·문 열림)에 재생된다 |
| 샘플 카드 | debug 빌드에만 든 시연·테스트용 목소리 카드(`app/src/debug/assets/cards/`). 지금은 맥 TTS로 만든 임시 음성이고 팀 녹음으로 바꾼다 |
| VoiceCardStore | 카드 ID로 목소리 카드 음원을 찾는 곳. 녹음 카드 → 샘플 카드 순서, 없으면 TTS로 대신 말한다 |
| 녹음 화면 | SC-08. 보호자 동의 뒤 미션 안내·차량 반응 카드를 아이 목소리로 녹음·삭제하는 화면. 주차 중, 이용 밖에서만 열린다 |
| CardStudio | 목소리 카드 녹음·보관·동의를 맡는 session 클래스. 녹음은 이 기기의 앱 폴더에만 저장한다 |
| 위치 동의 | 주차 중에만 보이는 "위치로 주변 가게 찾기" 버튼으로 받는 위치정보 이용 동의(LocationConsent). 동의 전에는 위치를 읽지 않고 데이터 없는 미션만 낸다 |
| 시연 경로 | `scripts/route.sh`가 `scripts/routes/`의 GPX 좌표를 에뮬레이터 GPS에 차례로 넣어 주행 위치를 재현하는 것 |
| 라운드 / 차례 | 놀이 하나의 단위 / 앱과 아이가 번갈아 말하는 한 번 |
| 사람 실측 | 무인 실행으로 판정할 수 없어 사람이 직접 확인해야 하는 완료 기준 |
| Reading | 차량 신호 하나의 값. 미지원(차가 안 줌) / 모름(아직 못 받음) / 값 중 하나. 안전 판정에서 "모름"은 위험한 쪽 |
| 연상어 | 직전 단어에서 떠오르는 단어(빨개 → 사과). 데이터는 game/WordChainData.kt |
| STT ready | STT 엔진이 듣기 준비를 마쳤다는 SDK 신호(`onReady`). `request()` 뒤 보통 0.1~0.6초 후에 온다. 그 전에 말하면 앞부분이 인식되지 않을 수 있다 |
| 아이 차례 신호 | 아이에게 말할 차례를 알리는 효과음. STT ready 뒤에만 낸다(F-02에서 구현) |
| 이용 | 보호자가 주차 중 시작을 누른 때부터 종료까지의 한 번. 메모리에만 있고 복원하지 않는다 |
| 멈춤 사유 | 지금 멈춰 있는 이유들의 집합(차량 신호, 다른 음성 안내). 하나라도 있으면 멈춤 |
| 휴식 | "잠깐 쉬자"·일시정지 버튼·무응답이 이어져 쉬는 상태. "다시 하자"로만 재개, 2분 지나면 무음 종료 |
| 다른 음성 안내 | 오디오 포커스를 잃은 상태. 내비 안내일 수 있지만 원인을 단정하지 않는다 |
| 음성 제어 | 재안내·휴식·재개·종료 4가지 공통 명령. 앱이 말하는 중에도 받는다 |
| 무음 종료 / 도착 마무리 | 종료 음성 없이 끝냄(그만·경고·장애·이탈·휴식 초과) / 도착 시 마무리 문장을 말하고 끝냄 |
| 응답 차례 / 입력 시도 | 게임이 아이 대답을 기다리는 순간 / 그 차례에 마이크를 연 한 번. 시도 ID로 늦게 온 결과를 걸러낸다 |
| SessionController | 이용 하나의 흐름(시작·안내·응답·멈춤·휴식·종료)을 한곳에서 처리하는 객체(설계서 2절, F-21) |
| PleosClient | Pleos SDK 호출·구독(차량 신호, 말하기·듣기, 효과음)을 모은 하나의 인터페이스(설계서 2절). 말하기·듣기는 끝날 때까지 기다렸다가 결과(Done·Heard·Failed 코드)를 돌려준다 |
| CarStatus | 화면이 쓰는 차량 상태 요약(연결 여부, 켜진 신호, 미지원 신호). ui가 pleos를 모르도록 session이 만들어 준다 |
| GameSession | 게임과 앱 사이의 약속. 앱이 입력(시작·대답·무응답·도착)을 주면 게임이 계획(말할 문장 + 다음 차례·휴식 제안·완료)을 돌려준다 |
| 관찰 미션 / 말잇기 | 메인 놀이(창밖 간판·사물 찾기) / 보조 놀이(연상해서 말 잇기) |
| 시뮬레이션 | sim.sh로 주입한 가짜 신호. 영상·로그에서 실제 연동과 구분해 표시한다 |
| Sim 덮어쓰기 | debug 빌드에서 `scripts/sim.sh`로 일부 신호만 가짜 값으로 바꾸는 장치 |

## 패키지
| 패키지 | 뜻 |
|---|---|
| pleos | Pleos SDK와 맞닿는 층(PleosClient). 다른 코드는 이 인터페이스만 안다 |
| session | 이용 흐름 관리(SessionController), 결정표, 음성 제어, 카드 재생 시점 |
| game | 놀이 내용(관찰 미션, 말잇기, 대화 규칙) |
| ui | 화면 |
| di | 객체 연결(의존성 주입) |
| debug | debug 빌드 전용 도구 |
| place | 장소 검색(중계 API 호출) |
| game/api | 게임 연결 계약(GameSession 등) |

## 안드로이드·차량 용어
| 용어 | 뜻 |
|---|---|
| AAOS | Android Automotive OS. 차량에 직접 설치되는 안드로이드. Pleos Connect가 이것 기반 |
| Pleos Connect | 현대차그룹 차량 인포테인먼트 플랫폼. 우리 앱이 돌아가는 곳 |
| 에뮬레이터 / AVD | PC에서 돌리는 가상 차량 화면 / 그 가상 기기 설정 |
| Virtual Console | 에뮬레이터에서 기어·문 등 차량 상태를 손으로 바꾸는 도구 |
| Activity | 화면 하나 |
| Application | 앱이 처음 뜰 때 한 번 만들어지는 객체. 초기화 담당 |
| BroadcastReceiver | 시스템이나 다른 앱이 보내는 "방송"을 받는 진입점 |
| AndroidManifest.xml | 앱의 신분증. 진입점, 권한, 필요 기능을 선언 |
| 권한(permission) | 앱이 민감한 기능(마이크, 차량 정보)을 쓰려면 manifest에 선언해야 하는 허가 |
| Gradle | 빌드 도구. 라이브러리를 받아 코드를 APK로 만든다 |
| APK | 안드로이드 설치 파일 |
| debug / release | 개발용 빌드(검증 도구 포함) / 제출용 빌드(서명, 난독화) |
| 서명(keystore) | release APK에 찍는 도장. 키 파일은 저장소에 올리지 않는다 |
| R8 | release 빌드에서 안 쓰는 코드를 지우고 이름을 줄이는 도구 |
| SDK | 기능을 쓰게 해 주는 라이브러리 묶음(Vehicle, NaviHelper, STT, TTS, FusedLocation) |
| Capability | "이 차가 이 기능을 지원하는가"를 묻는 Pleos API |
| Telltale | 계기판 경고등(주차 브레이크, 경고, 방향지시등 등). 비상등·주차 브레이크·경고는 이것으로만 읽힌다 |
| Callback / Listener | 값이 바뀔 때 SDK가 우리 코드를 불러 주는 방식 |
| Flow | 시간에 따라 바뀌는 값을 흘려보내는 Kotlin 도구(신호 상태를 이걸로 전달) |
| StateFlow | 항상 "현재 값"을 하나 들고 있는 Flow. 화면 상태를 담는다 |
| Jetpack Compose | 코드로 화면을 그리는 안드로이드 방식. 상태가 바뀌면 화면이 다시 그려진다 |
| MVVM | 화면(View)·화면 상태 관리(ViewModel)·로직(Model)을 나누는 구조 |
| ViewModel | 화면 하나의 상태를 들고, 사용자 행동을 받아 로직에 전달하는 클래스 |
| dp / sp | 화면 밀도와 무관한 크기 단위 / 글자 크기 단위(사용자 글꼴 설정 반영) |
| 코루틴 | 기다리는 일(음성, 신호)을 멈춤 없이 처리하는 Kotlin 방식 |
| Fake | 테스트용 가짜 구현. 실제 차 없이 신호를 마음대로 바꿀 수 있다 |
| CarUxRestrictions | 주행 중 화면 제한(키보드, 긴 글 등)을 알려 주는 차량 OS 기능 |
| distraction-optimized | "주행 중에도 띄워도 되는 화면"이라는 선언 |
| 오디오 포커스 | 여러 앱이 동시에 소리를 낼 때 누가 말할지 정하는 규칙(내비 안내가 우선) |
| TTS / STT | 글을 말로(Text To Speech) / 말을 글로(Speech To Text) |
| ON_DEVICE | 인터넷 없이 차 안에서 처리하는 음성 모드 |
| VHAL | 차량 하드웨어 값을 OS에 전달하는 층. 에뮬레이터에서 속도 등을 주입할 때 쓴다 |
