# 벌써도착 이용 단계별 필수 기능과 파생 기능

이용 준비부터 종료까지 다섯 단계의 공통 이용 기능과 동작 정책을 정리한다.

- **필수 기능:** 각 단계가 성립하는 데 필요한 핵심 동작.
- **파생 기능:** 필수 기능을 실제로 동작시키는 데 필요한 준비, 입력 처리, 상태 유지, 오류 대응과 정리 기능. 연결된 필수 기능의 구현 범위에 포함한다.

## 1 이용 준비

새 이용은 주차 상태가 확인되고 음성 사용 준비가 끝난 경우에만, 보호자가 화면에서 시작을 요청해 실행한다. 종료 후 다시 시작할 때도 같은 조건을 적용한다. 주차 상태를 확인할 수 없으면 새 이용을 시작하지 않는다.

| 필수 기능 | 파생 기능 | 요구사항 |
| --- | --- | --- |
| 이용 시작 | 음성 사용 준비 | 마이크 권한과 음성 입출력 사용 가능 여부를 확인하고 필요한 권한을 요청한다. 준비가 끝나기 전에는 이용을 시작하지 않는다. |
| 이용 시작 | 시작 가능 여부 안내 | 주차 상태와 음성 사용 준비를 확인한 뒤 시작 요청을 처리한다. 시작할 수 없으면 이유와 필요한 조치를 화면에 안내한다. |

| 이용 시작 | 중복 시작 방지 | 이미 이용 중일 때 시작을 다시 요청해도 새 이용을 만들지 않는다. 일시중단한 이용은 재개 요청으로 이어간다. |

안내와 응답을 주고받으며 진행한다. 응답을 얻지 못한 상황과 음성 기능 자체를 사용할 수 없는 장애를 구분한다.

| 필수 기능 | 파생 기능 | 요구사항 |

| 공통 진행 관리 | 차례 전환 | 안내, 아이의 응답, 앱의 반응 순서로 진행한다. 중단하거나 종료한 상태에서는 다음 활동으로 넘어가지 않는다. |
| 공통 진행 관리 | 진행 위치와 접수 응답 유지 | 현재 차례와 중단 전에 접수를 마친 응답을 유지한다. 이미 받은 답을 다시 요구하거나, 이미 반영한 응답을 중복 반영하지 않는다. |
| 진행 막힘 처리 | 재참여 안내 | 음성 기능은 사용할 수 있지만 무응답이거나 응답 내용을 알아듣지 못한 경우, 현재 해야 할 일을 다시 안내하고 응답할 기회를 제공한다. |
| 진행 막힘 처리 | 무응답에 따른 휴식 | 재참여 안내 뒤에도 응답을 얻지 못하면 쉬는 상태로 전환한다. 휴식 전환을 짧게 알린 뒤 추가 응답 요청과 반복 안내를 멈추고, 명시적인 재개 또는 종료 요청을 기다린다. |

개별 발화를 알아듣지 못한 경우에는 재참여 안내를 적용한다. 내비 안내에 양보하기 위한 일시적인 출력 중단은 음성 기능 장애로 처리하지 않는다. 내비 안내 중에는 일반 응답 대기와 무응답 판정을 진행하지 않는다.

사용자 요청이나 무응답으로 쉬는 상태와, 내비 안내 때문에 잠시 멈춘 상태를 구분한다.

접수 완료는 음성에서 응답 내용을 얻어 현재 차례의 입력으로 받아들인 상태를 뜻한다. 중단 전에 말했더라도 접수를 마치지 못한 응답은 재개 후 새 응답으로 취급하지 않는다.

## 공통 이용 조건

- 주행 중 참여·재안내·일시중단·재개·종료를 위해 화면 조작을 요구하지 않는다. 종료 상태 표시는 확인을 위한 정보이며 조작을 요구하지 않는다.
- 일반 응답을 받는 차례와 이용 제어 요청을 받는 조건을 구분한다. 사용자 역할에 따른 음성 화자 식별을 요구하지 않으며, 아이나 보호자의 제어 요청을 같은 정책으로 처리한다.
- 중단 중에는 제어 요청을 받을 수 있어야 한다. 종료 후에는 음성 인식을 유지하지 않으며, 새 이용은 주차 중 화면에서 시작한다.
- 내비 안내에 양보하는 규칙은 첫 안내·재안내·휴식·재개·종료 안내를 포함한 앱의 모든 음성 출력에 적용한다. 내비 안내 중 발생한 휴식 전환은 화면 상태로 표시하고, 사용자가 새로 요청하기 전에는 휴식 안내를 지연 재생하지 않는다.
- 진행 위치와 응답은 현재 이용에서 중단 후 재개하는 범위로 유지한다. 종료한 이용을 복원하지 않는다.
- 도착은 이용을 마치는 상황이며, 아이나 보호자의 종료 요청으로 처리한다. 목적지 자동 감지는 별도 기능이다.
